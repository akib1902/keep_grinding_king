Recipes to try

  1. Start the local server. Run node scripts/serve.mjs in the project root, then open http://localhost:4321/demo/shop.html.
  2. Load the extension. Visit chrome://extensions, turn on Developer mode, choose "Load unpacked", and select this folder.
  3. Open the side panel. Click the scraperStack icon. Name the recipe "Bookshop catalogue".
  4. Pick the list. Press Pick item, then click any book card. Auto-detect should map Title, Price, Image, Link and Rating.
  5. Add pagination. Enable it, pick the Next → link, set max pages to 3.
  6. Scrape. Run three pages, then export CSV. Show 18 rows.
Why this page is a good test Every card has a stable class, a shared parent, a real link and a real image. The pager is a genuine <a href> until the last page — at which point the next control disappears, so the scraper has to stop on its own.

The table page is the control case: no pagination, fixed rows, one field per cell. If a scrape fails there, the selector is wrong, not the site.
