About scraperStack

Version 1.0.0
Shortcut Ctrl+Shift+Y
Build Manifest V3 · no bundler · no dependencies
Permissions used
  • Read page contentOnly the page you invoke the picker on, to find and extract elements.
  • Scripting + active tabInjects the picker into the page you are viewing, and re-attaches it after a reload.
  • Side panelKeeps the builder open while you click elements on the page.
  • Storage + unlimited storageSaves recipes and datasets locally. No account, no server.
  • Context menus + tabsAdds "Scrape this page" to the right-click menu and knows which tab to act on.
scraperStack makes no analytics or network calls of its own. The only requests it sends are to the same site you are scraping, when you choose the "follow next link" strategy.
